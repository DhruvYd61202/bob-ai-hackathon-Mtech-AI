# Source Code Directory

This directory contains the entire source code for the DeepFake ForensicAI project. 

## Structure
- `backend/`: Contains the FastAPI python backend, deep learning models (PyTorch), cryptographic chain of custody logic, and IBM Bob agent integration.
- `frontend/`: Contains the React 18, TypeScript, and Vite frontend.
- `data/`: Contains local file storage for uploads, cases, reports, and cached model weights.

Please refer to `docs/setup-guide.md` for running instructions.
